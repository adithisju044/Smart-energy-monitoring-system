# Smart-energy-monitoring-system
 IoT + ML based electrical monitoring and prediction system

## Overview

This project presents an IoT-based real-time electrical monitoring and prediction system using ESP32 and PZEM-004T sensor. The system collects electrical parameters such as voltage, current, power, frequency, and power factor, and uses machine learning techniques for analysis and prediction.

## Features

* Real-time electrical parameter monitoring
* Data collection and storage in CSV format
* Cloud integration using ThingSpeak
* Load classification using XGBoost
* Power prediction and energy forecasting
* Anomaly detection using Isolation Forest

## Hardware Used

* ESP32
* PZEM-004T Sensor
* Electrical Loads (Bulb, Charger, Kettle, etc.)

## Software Used

* Arduino IDE
* Python (Pandas, NumPy, Scikit-learn)
* ThingSpeak Cloud Platform
